# FindAI MVP v2

Prva ozbiljnija verzija FindAI-a: pretraga, kategorije i 40+ početnih AI alata.

## Besplatno pokretanje na računalu

1. Instaliraj Node.js (LTS).
2. Raspakiraj ZIP.
3. U terminalu uđi u mapu projekta.
4. Pokreni:

```bash
npm install
npm run dev
```

5. Otvori `http://localhost:3000`.

## Besplatna objava

Projekt je pripremljen za Vercel. Nakon što ga staviš na GitHub, možeš ga importati u Vercel i dobiti besplatan `vercel.app` link.

## Važno za buduću verziju

- provjeriti aktualne cijene i free planove svakog alata prije objave
- dodati detaljne stranice za svaki alat
- dodati SEO metadata, sitemap i robots.txt
- napraviti bolje razumijevanje prirodnog jezika
- dodati Supabase tek kad nam treba korisnička baza/favoriti
- dodati affiliate linkove tek nakon provjere programa
- AdSense dodavati tek nakon što stranica ima kvalitetan originalan sadržaj i promet
